

\# StructGround-UQ



Research project on statistical risk certification for structural damage segmentation using weak bounding-box annotations and dense segmentation masks.



\## Dataset

dacl10k (stored separately from the Git repository).



\## Research Timeline

October 26, 2026 - January 17, 2027.



\## Project Structure

\- configs/: Experiment configurations

\- data\_cards/: Dataset documentation

\- splits/: Dataset split information

\- src/segmentation/: Segmentation utilities

\- src/proxies/: Proxy mask methods

\- src/risk/: Risk calibration methods

\- experiments/: Experimental scripts

\- tests/: Unit tests

\- results/: Experimental results

\- paper/: Research documentation
